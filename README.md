# 📒 올인원 메모장 (1단계)

메모 + 할 일 + 캘린더를 날짜로 연결한 웹 메모장입니다. 로그인 없이 내 브라우저에만 저장돼요.

## 가장 쉬운 실행 방법
폴더의 **`올인원메모장_시작.bat`** 을 더블클릭하세요. 서버가 켜지고 브라우저가 자동으로 열려요.
(끄려면 열린 검은 창을 닫으면 됩니다.)

## 직접 실행하는 방법 (로컬 웹)
1. 이 폴더에서 PowerShell을 엽니다. (폴더 빈 곳에서 Shift + 우클릭 → "여기에 PowerShell 창 열기")
2. 아래 명령을 입력합니다. (작은 웹 서버를 켜는 명령이에요)
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\serve.ps1
   ```
3. 크롬/엣지에서 **http://localhost:5000** 으로 접속합니다.
4. 끄려면 PowerShell 창에서 `Ctrl + C`.

> 포트(5000)가 이미 쓰이면 `$env:PORT=5001` 을 먼저 입력한 뒤 위 명령을 실행하고, 주소 끝 숫자도 바꿔 접속하세요.

## 파일 설명
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대 |
| `style.css` | 색·모양 (맨 위 `:root`의 색 변수만 바꾸면 전체 색이 바뀜) |
| `app.js` | 저장·화면 전환·다크 모드·예시 데이터 |
| `memo.js` / `todo.js` / `calendar.js` / `dashboard.js` | 각 화면의 기능 |
| `serve.ps1` | 로컬 웹 서버 (한글을 넣지 마세요. PowerShell이 글자를 잘못 읽을 수 있어요) |

## 내가 직접 바꿔 볼 수 있는 곳
- **서비스 이름**: `index.html`의 `<title>`과 `<h1 class="logo">`
- **메인 색**: `style.css`의 `--accent` (밝은 모드/어두운 모드 각각)
- **메모 색**: `style.css`의 `--c-pink` 등 5개
- **예시 데이터**: `app.js`의 `makeSample()` (지우면 빈 화면으로 시작)

## 데이터 저장 위치
브라우저의 localStorage(키: `allinone-memo-v1`). 다른 브라우저나 기기와는 공유되지 않으며,
화면 아래 "모든 데이터 지우기"로 초기화할 수 있어요. 민감한 개인정보는 적지 마세요.

## 2단계(AI) 준비
데이터 읽기/쓰기는 `app.js`의 `store` 한 곳에 모여 있어, 나중에 서버를 붙일 때 이 부분만 바꾸면 됩니다.
AI의 API 키는 화면 코드에 넣지 말고 반드시 서버에 보관하세요.

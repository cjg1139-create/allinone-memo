# 두번째 PC 소개 웹페이지 (PRD 1단계 시안)

기업의 폐PC를 비영리단체에 연결하는 PC 나눔 서비스의 소개 페이지입니다.

## 보는 법 (로컬 웹)
1. `start-second-pc.bat` 파일을 더블클릭합니다.
2. 검은 창이 뜨고 잠시 뒤 브라우저가 `http://localhost:5100` 주소로 자동으로 열립니다.
3. 끝낼 때는 검은 창을 닫으면 됩니다. (설치 필요 없음, 내 컴퓨터에서만 보임)

> 메모장(5000번)과 주소가 달라서 두 개를 동시에 켜도 됩니다.
> `index.html`을 직접 더블클릭해도 열리지만, 환경에 따라 소식·후기 칸이 비어 보일 수 있어 위 방법을 권장합니다.

## 파일 설명
| 파일 | 역할 |
|---|---|
| `index.html` | 메인 소개 페이지 (PRD 6장 화면 전체) |
| `apply.html` | 기업 PC 나눔 / 비영리단체 신청 폼 (임시 항목, 서버 저장 없음) |
| `style.css` | 디자인. 맨 위 `:root`의 색 코드를 바꾸면 전체 색이 바뀝니다 |
| `content.js` | 소식·후기·공지·파트너 등 **고쳐 쓰는 내용** |
| `main.js` | 메뉴, 슬라이드, 폼 입력 확인 동작 |

## 내용 고치는 법
- 소식 제목, 후기, 공지, 파트너 이름 → `content.js`의 따옴표 안 글자만 바꾸고 저장 후 새로고침(F5)
- 문구·버튼 글자 → `index.html`에서 해당 글자를 찾아 수정
- 배너 사진 → 현재는 색 블록 자리표시. 사진이 생기면 `index.html`의 `slide` 부분을 `<img>`로 교체

## 아직 정해지지 않은 항목 (임의로 채우지 않음)
1. 후원금 구조(기본 금액, 후원 적용 금액, 기업 부담 금액) → 화면에 `[금액] 미정` 표시
2. 개인 PC 수요자·폐기 희망자를 서비스 범위에 넣을지 → 별도 화면 없음
3. 신청서에 받을 항목 → 현재 임시 5개 항목
4. 성공 기준 수치 → 화면에 표시하지 않음
5. 후기, 파트너 로고, 사업자 정보 → "준비 중" 표시
6. 데이터 삭제 방법·증명서 양식 → 전문가·관련 규정 확인 후 확정 필요
7. 해외 기증 연계 진행 여부 → "준비 중" 배지
8. 이용약관·개인정보처리방침·ESG 리포트·후원금 사용 내역 본문 → 팀이 작성 필요
9. 신청서 저장 방식(구글 폼, 이메일 등) → 현재는 입력 확인만 하는 시연

## 주의
신청서는 개인정보(연락처 등)를 받으므로, 실제 운영 전에 개인정보처리방침과 동의 문구를 확정해야 합니다.
